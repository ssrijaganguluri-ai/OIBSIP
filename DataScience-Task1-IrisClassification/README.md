# Task 1: Iris Flower Classification

## Overview
This project classifies Iris flowers into three species (Setosa, Versicolor, Virginica) based on sepal and petal dimensions using Machine Learning.

## Technologies Used
- Python
- Pandas & NumPy
- Scikit-Learn
- Matplotlib & Seaborn

## Features
- Exploratory Data Analysis (EDA)
- Machine Learning Model Training (Logistic Regression / Random Forest)
- Performance Evaluation (Accuracy & Confusion Matrix)
